# Rental Return Checklist

Date: 2026-11-11

## Return workflow

- Confirm the rental record and selected vehicle before accepting a return.
- Validate the return date against the original booking period.
- Record any applicable condition notes before completing the workflow.
- Update vehicle availability only after the return is confirmed.

## Verification checklist

- [ ] A valid return completes successfully.
- [ ] An unknown booking is rejected with clear feedback.
- [ ] Duplicate return attempts do not create duplicate records.
