# RideRent

RideRent is a polished bike rental demo built with plain HTML5, CSS3, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

```bash
cd ride-rent
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included functionality

- Responsive premium rental interface
- Bike search, filtering, sorting, category navigation
- Favorites stored in localStorage
- Booking modal with date, add-on, fee, and total calculation
- Rental history with cancellation
- Dashboard stats and spending visualization
- Notifications, toast messages, modal interactions
- Light and dark themes persisted locally

The visual bike illustrations are CSS-generated so the project works without broken external image links.
